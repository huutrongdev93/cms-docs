# AI (Laravel AI SDK)

> **Framework:** `packages/skilldo/framework/src/Ai/` (`SkillDo\Ai\*`)
> **CMS:** `packages/skilldo/cms/src/Ai/` (`SkillDo\Cms\Ai\*`)
> **Thư viện:** [`laravel/ai`](https://github.com/laravel/ai) v1, có sẵn trong lõi

Hướng dẫn đầy đủ nằm ở mục **[AI](../16-AI/01-Tong-quan.md)**. Tóm tắt nhanh:

```php
// 1. Khai plugin có dùng AI → tab Cấu hình hệ thống → Trí tuệ nhân tạo (AI) hiện ra
add_filter('cms_ai_consumers', fn ($c) => $c + ['my-plugin' => 'Tên plugin']);

// 2. Gọi AI: nhà cung cấp, API key, model lấy từ tab cấu hình
use SkillDo\Ai\Ai;
use function Laravel\Ai\agent;

try {
    $text = agent('Bạn là trợ lý viết nội dung tiếng Việt.')->prompt($prompt)->text;
} catch (\Throwable $e) {
    response()->error(Ai::errorMessage($e));
}
```
